# Infosys Project

## Project Description
This project demonstrates collaborative development using GitLab. 
It showcases version control, issue tracking, feature branching strategy, and merge request workflow.

## Features
- User registration
- Login validation
- UI improvements

## Technologies Used
- Python / Django / HTML / CSS (write what you are actually using), randomforest and mediapipe for training safe activites, and Yolo for unsafe activites training

## Branching Strategy
This project follows feature branching:
- main → production-ready code
- feature/* → new features and bug fixes

## How to Run
1. Clone the repository
2. Install dependencies
3. Run the application

Run:
python manage.py makemigrations
python manage.py migrate
